# Detailed Topic Guides

These long-form guides accompany the notebooks in [../Practice](../Practice). Start from the [curriculum index](../PRACTICE_README.md) to select a prerequisite-based route.

Every guide is designed as a standalone conceptual and engineering reference. It includes prerequisites, a teach-from-zero explanation, concept map, theory, function-by-function sequence, contracts, decision criteria, scaling, interpretation, evaluation, error analysis, debugging, tests, production architecture, monitoring, responsible use, exercises, a capstone rubric, and interview questions.

Use the notebook for executable practice and the guide for deeper reasoning. Mastery requires both: code without explanation is fragile, while explanation without implementation is untested.
